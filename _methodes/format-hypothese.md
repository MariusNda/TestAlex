# Format d'une hypothèse

> Appelé par la **Règle n°2** de `CLAUDE.md`.

Format, dans `hypotheses.md` :

```markdown
### DSP3-H29 · Révocation d'un consentement TPP
**Statut** : 🟡 OUVERTE — ouverte le 2026-09-01
**Source** : [SRC: atelier BFB du 2026-08-24]
**Question** : la révocation coupe-t-elle l'access token, ou seulement le refresh token ?
**Dépendances** : DSP3-EX-183, DSP3-EX-188 · brique `open-banking-consent-management` · C2.1
**Historique** : 2026-09-04 — alimentée par DSP3-ET-02 §4, sans changement de statut
```
